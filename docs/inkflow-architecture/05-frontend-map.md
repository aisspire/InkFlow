# 前端组件与状态

- `EditorWorkbench.tsx`：文章会话、持久化草稿、当前工作副本、源码/预览、建议处理、版本、候选冲突对比与主编辑稿回传；文章搜索弹窗支持系统文件选择，工作区选择在保存草稿后切换并刷新会话。
- `DirectoryField.tsx`：目录手输与原生“浏览…”按钮，管理选择中、取消和错误；用于工作区与设置，选择只更新字段。
- `api.ts`：统一携带 URL 编码的工作区标识，调用本机选择 API；其它标签页切换后旧上下文请求由服务端拒绝。
- `OpenArticles.tsx`：已打开文章的真实目录层级、折叠、选中、关闭和后台运行摘要；工作区选文使用独立搜索弹窗。
- `SourceEditor.tsx`：CodeMirror 原文、统一标注、UTF-16 范围、正文问题双向选择、按文章缓存 EditorState/滚动/撤销；外部替换作为独立历史步骤。
- `useWorkflow.ts`：按工作区/文章选择运行、历史与节点；当前运行 SSE，所有文章摘要轮询，异步响应按文章上下文和 run_id 校验。
- `App.tsx`：顶部工作流选择、当前运行、停止、结束检查与待办；辅助流程图、详情和当前文章历史；旧未关联历史单独查看。
- `WorkflowCanvas.tsx`：运行自身真实图与实际执行状态，保留桌面交互、键盘与窄屏列表。
- `NodeDetails.tsx`：逐项脱敏、候选差异、追问、最终文章审核与输出；审核输入按 pending_id 保留，切换窗格或文章不丢失。
- `DocumentDiff.tsx` / `diff.css`：脱敏确认、候选冲突与生成稿载入的共用只读可视化对比；红删绿增、行内标记、行号和统计，支持上下文展开、跳转、放大与并排/逐行布局，窄容器逐行显示。
- `textDiff.ts`：完整文本的有界行匹配与 Unicode 行内匹配，保留行尾与 BOM 差异；大段重写回退完整增删块，界面按需分批渲染。
- `NewRunDialog.tsx`：当前文章工作副本的正式处理运行，不提供无归属的上传/粘贴入口。
- `WorkflowDocumentBridge.tsx`：其它生成稿显式差异对比、候选校验、载入与主编辑稿提交；已确认脱敏稿通过动作直接推进工作副本。
- `MarkdownPreview.tsx`、`ArticleEditor.tsx`、`SettingsPage.tsx`：沿用安全预览、文章属性编辑和设置。

数据权威：SQLite editor_docs 是持久化工作副本；编辑器中的尚未持久化输入由当前文章会话持有。RunManager 记录运行与审核事实，前端建议只是本地编辑映射投影。运行输入、检测快照与候选不得反向覆盖正在输入的正文。历史选择不安装正文，不启用历史修改按钮。

桌面保留浅色三栏；窄屏文件 Drawer 带焦点管理，辅助区纵向排布。隐藏源码预览和折叠窗格不清空编辑状态；切换文章用独立 EditorState。刷新恢复已打开列表、当前文章和草稿，撤销栈仅限当前页面会话。
