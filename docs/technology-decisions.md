# InkFlow 技术选型

确认日期：2026-11-06

状态：近期编辑闭环已按本选型实现，并完成隔离目录、浏览器与真实模型调用验证；限制见文末。

## 目标与选型

服务于 [产品路线](../roadmap.md) 的近期编辑闭环：打开真实文章、全文检查、逐条处理建议、手动编辑、版本恢复和保存。优先兼容用户已有的 Markdown／MDX 文件，复用项目已完成的工作。

| 层次 | 选型 | 原因与实施状态 |
| --- | --- | --- |
| 前端 | React + TypeScript | 已使用；适合文件、正文、建议之间的状态联动，类型约束有助于保持接口一致。 |
| 构建 | Vite，沿用 npm 与现有 lockfile | 已使用；适合本地 Web 工作台，近期无须引入服务端渲染框架。 |
| UI 组件 | MUI + 自定义主题 | 已使用；复用菜单、表单、弹窗等交互，通过主题修改视觉，不为此次样式调整迁移组件库。 |
| 布局与样式 | CSS Grid / Flex + CSS 变量 | 三栏布局与响应式行为使用 CSS；颜色、字体、间距、圆角和阴影集中维护，与 MUI 主题保持一致。 |
| 正文编辑 | CodeMirror 6 | 已接入。以原始文本为基础，适合范围高亮、局部替换和编辑后的位置映射。 |

## 编辑器取舍

采用 **CodeMirror 6 编辑原文 + 独立排版预览**。HTML 样板中的纸张排版用来确认布局与阅读体验，不等同于承诺直接在富文本页面中编辑全部 Markdown／MDX 语法。

- CodeMirror 的 decorations 与位置映射可以承载局部建议高亮及编辑后的位置更新，但不会自动判断建议是否仍然有效。
- 建议需要绑定文章版本、原文范围和原文内容；手动修改后必须重新判断适用性，失效建议禁止直接采用。
- CodeMirror 的撤销／重做用于编辑会话；持久化文章历史与版本恢复由应用层实现，不能用编辑器撤销栈或 Agent checkpoint 替代。
- 保存时保留未修改的 frontmatter、MDX 片段、代码块、换行及周边文件。预览结果不作为重建整份源文件的依据。
- 不执行文章中的任意 MDX／JavaScript。暂不支持的预览内容需保留源文并说明限制。

Tiptap 更适合直接编辑排版后的富文本，但 Markdown 解析／序列化有支持边界，不能默认保证任意 MDX 无损往返。只有当产品明确转向所见即所得优先时，再评估该方案及格式兼容成本。

## UI 与预览方式

后续使用本地 HTML 样板 `inkflow-preview.html` 预览和调整 UI，不再通过 Figma 继续设计。`InkFLow.png` 保留为布局参考，`inkflow-preview.png` 为 HTML 的视觉记录。这些设计素材仅保留在本地，不随源码交付；当前工作台截图见 [README](../README.md)。

- 黑白是主色调，采用低反差浅色侧栏、白色正文和轻边界；避免深色侧栏与内容形成强烈反差。
- 通过字体、间距、边框、轻阴影和选中态建立层级，避免平铺或堆叠说明文案。
- 当前建议分类配色：绿色表示表达优化，紫色表示结构，蓝色表示一致性；正文标记、编号和侧栏对应。
- 类型与处理状态独立建模。待处理、已采用、已忽略、失效等状态同时使用文字或图标，不仅靠颜色表达。
- 样板中的搜索和展开等预览交互不代表业务功能已经完成；样板的文章与时间均为示例数据。

继续使用 MUI，通过自定义主题实现上述视觉。暂不引入 Tailwind CSS + shadcn/ui，避免同时维护两套组件与样式约定；这不是对其能力的否定，而是基于现有项目的迁移成本。

## 实施顺序

1. 保留 HTML 作为设计参照，将布局、主题和组件迁入现有 React 应用；接入真实文件的读取、原文编辑、预览及保存。
2. 接入全文检查和局部建议，完成正文联动、采用、拒绝并反馈、忽略和重新检查。
3. 完成建议失效判断、文章版本记录与恢复，验证完整闭环。

发布、自动发布、聊天、定时维护和多站点扩展按 roadmap 后续推进。不要因本次 UI 开发提前扩大范围。

本地 `development-prompt.md` 是可选开发提示词，不随源码交付；当前规则见 [统一工作台与工作流](workbench-and-workflows.md)。

## 当前实现与限制（2026-11-06）

- 通过 --workspace 在启动时授权文章根目录，默认配置目录。React 首页为编辑工作台，原任务流程与 CLI 保留。
- CodeMirror 使用原始 UTF-16 文本偏移，只按 LF 分行，保留既有 CR / CRLF 与 BOM；新插入换行为 LF。Markdown 预览不作为保存来源。
- 建议绑定检查版本与原文，编辑时映射定位并复核。重复文本或聚合修改存在歧义时保守失效；全文结构建议由人工修改处理。
- 文章上限 2 MB，全文检查上限 24,000 Unicode 字符，不截断。历史面板显示最近 200 条，SQLite 保留完整记录。
- 不执行 MDX / JavaScript，不加载预览中的本地相对资源；周边资源保持原样。
- 检查返回核验文章版本；文件保存核验磁盘指纹，冲突可读取磁盘并将原草稿留在历史。编辑器撤销、业务版本与 Agent checkpoint 相互独立。
